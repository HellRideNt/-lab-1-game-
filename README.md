## Лабораторная №1 Hello world

**Вариант №6 — Поиск тяжестей.** Запросить у пользователя ID предмета `a`. Найти и вывести на экран индексы всех слотов, где лежат предметы с ID строго больше числа `a`.

## Лабораторная №2 game (2)

**Вариант №6 — Проверка рецептов крафта.** В `input.txt` записан список рецептов создания предметов в формате `Название_предмета: ID1 ID2 ID3`. Программа проверяет каждый рецепт, сопоставляя требуемые ID с текущим массивом инвентаря игрока и учитывая количество одинаковых предметов. В `output.txt` выводится вердикт `[ДОСТУПНО]` или `[НЕ ХВАТАЕТ РЕСУРСОВ]` с названиями недостающих компонентов.

## Лабораторная №2 game (3)

**Вариант №7 — Телепортационные ловушки.** На карте разбросаны руны (`^`). При наступании на руну герой мгновенно переносится на случайную пустую клетку, а руна исчезает.

## Лабораторная №5

**Вариант №2 — Недвижимость и апгрейд дома (`struct Farmhouse` и `enum HouseLevel`).** Добавить структуру дома фермера (тип жилья через `enum`: Палатка, Хижина, Дом, Особняк; стоимость улучшения; уровень комфорта). В меню появляется пункт «Улучшить жильё» за золото. Уровень жилья влияет на «Отдых»: в Палатке стамина восстанавливается только до 70% от максимума, в Хижине — до 100%, а в Доме и Особняке герой получает утренний бонус бодрости (временная стамина поверх максимума на +15/+30 ед.).

## Сборка

Из корня проекта:

```sh
gcc src/main.c src/player.c src/map.c src/utils.c -o game
```

Файлы `items.txt` и `input.txt` программа читает из корневой папки проекта.
